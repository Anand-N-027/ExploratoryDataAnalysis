README
Adult Income Classification with Machine Learning
A notebook-based project that explores the Adult dataset and builds models to classify income into two categories: <=50K and >50K.

The project combines exploratory analysis, preprocessing, baseline classification, and hyperparameter tuning, with XGBoost as a central model. It also includes logistic regression comparisons, a Random Forest tuning experiment, and a PyTorch neural network example.

Features
Exploratory visualizations of education, working hours, and income

Numerical feature correlation analysis

Income class-distribution analysis

Baseline XGBoost classification with a classification report

XGBoost feature-importance visualization

Numerical and categorical preprocessing pipelines

Hyperparameter tuning with grid search and randomized search

Stratified nested cross-validation experiments

Logistic regression comparison and PCA-based decision-boundary visualization

A separate synthetic linear regression example

A PyTorch quickstart and binary-classification neural network implementation
